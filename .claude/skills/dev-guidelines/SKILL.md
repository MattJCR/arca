# Dev Guidelines

## Cuándo utilizarla

Siempre que se escriba, edite o revise código.

## Responsabilidad

Aplicar de forma consistente las reglas de desarrollo del proyecto: especificación estricta, simplicidad, preservación del comportamiento, tipado, tests, seguridad, gestión de errores y política de idioma (código en inglés, UI en español).
