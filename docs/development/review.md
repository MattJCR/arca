# Checklist de revisión y autoevaluación

Antes de entregar cualquier implementación, verifica:

- ¿Compila correctamente?
- ¿Respeta las convenciones del proyecto?
- ¿Introduce duplicación?
- ¿Puede simplificarse?
- ¿Respeta la arquitectura?
- ¿Mantiene el comportamiento existente?
- ¿Incluye las pruebas necesarias?
- ¿Los nombres son claros?
- ¿Las responsabilidades están bien separadas?
- ¿Otro desarrollador entendería este código rápidamente?

Si alguna respuesta es negativa, mejora la implementación (refactoriza) antes de entregarla.

Nota: este checklist fusiona las secciones "Autoevaluación antes de responder" y "Mentalidad de revisión" del documento original de reglas de desarrollo, que contenían preguntas prácticamente idénticas.
