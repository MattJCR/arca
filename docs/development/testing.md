# Pruebas obligatorias

Toda modificación funcional debe ir acompañada de pruebas.

Prioriza:

- Tests unitarios.
- Tests de integración.
- Tests de regresión.

Las pruebas deben cubrir:

- Casos esperados.
- Casos límite.
- Casos de error.

Una tarea no se considera terminada si no existen pruebas adecuadas.
